📚 College Viva & Technical Concepts

1. How does the Neural Network compute this prediction? (Forward Pass)

1. Feature Scaling: Raw inputs are normalized with training set mean and standard deviation: z = (x - μ) / σ.
2. Hidden Layer (8 neurons, ReLU): Computes A1 = max(0, X · W1 + b1).
3. Output Layer (3 neurons, Softmax): Computes σ(z)_i = e^(z_i) / Σ e^(z_j) producing normalized probabilities summing to 1.0.
4. Argmax: Highest probability neuron selects the predicted weather category.

2. Why use StandardScaler and how does it prevent Data Leakage?

Temperature (5–45°C) and Humidity (15–100%) have different numerical magnitudes. Without scaling, larger humidity values would dominate gradient descent weight updates. Data Leakage Prevention: The scaler is fitted only on the training split (scaler.fit(X_train)) and never on the test split.

3. Why use Sparse Categorical Cross-Entropy Loss?

Sparse Categorical Cross-Entropy is used when target labels are integers (0 = Sunny, 1 = Cloudy, 2 = Rainy) rather than one-hot encoded vectors. It computes the log-loss error between the true class and the predicted softmax probability.

4. Why 8 Hidden Neurons and ReLU?

8 neurons offer enough capacity to learn non-linear decision boundaries between 3 classes in 2D space without overfitting. ReLU (max(0, x)) avoids vanishing gradients and allows fast backpropagation.

5. How to run the Python Streamlit App locally?

Run: streamlit run app.py in Windows PowerShell inside the repository directory. The Streamlit app loads the saved models/weather_model.keras and models/scaler.joblib files.
